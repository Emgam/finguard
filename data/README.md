# Data

The raw data is **not** committed. Download the IEEE-CIS Fraud Detection competition data
from Kaggle (accept the competition rules first):

```bash
kaggle competitions download -c ieee-fraud-detection -p data/raw
unzip data/raw/ieee-fraud-detection.zip -d data/raw
```

Expected files and MD5 checksums (verified by `make data`):

| File | Size | MD5 |

| train_identity.csv | 26.5 MB | 8487db5001c8bad139f3318d5d3db416 |

`data/interim/` receives the joined, fixed tables (`train.parquet`, `test.parquet`,
`manifest.json`). It is regenerated by `make data` or notebook 01.

Note: the "test" files have **no labels**. In FinGuard they are the *later period* used
for drift monitoring and batch-scoring demos, never for model metrics.
